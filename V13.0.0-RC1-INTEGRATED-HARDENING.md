# BuzzBee ERP v13.0.0 RC1 — Integrated Hardening

Esta entrega concentra en una sola candidata de producción los pasos que estaban planeados por separado: UX e interacción, QA visual, idioma, regresión estática, deployment hardening y feature freeze.

## Incluido
- Capa global `global-ui-v13.css`: controles, toolbars, tablas, estados vacío/carga/error, paginación, validación, foco, modales y responsive.
- Mantiene el estándar de switches 40x22 px.
- Diccionario es-MX ampliado para estados operativos y de plataforma.
- Corrección de copy visible en inglés detectado en Marketing.
- `apps/web/vercel.json` para SPA cuando Vercel usa `apps/web` como Root Directory.
- QA consolidado `npm run qa:rc`.
- QA específicos: `qa:ux-interactions`, `qa:ui-language`, `qa:deployment`.
- API health/readiness conservados y versión visible actualizada.

## No incluido / no se debe asumir
- No hay cambios de Prisma ni migraciones.
- No se ejecutan mutaciones contra una DB de producción.
- Las suites runtime E2E que requieren PostgreSQL/API levantada deben ejecutarse en staging del usuario.
- El build Vite debe validarse en el entorno local/CI con dependencias instaladas.

## Gate de staging
Con API + PostgreSQL de staging levantados ejecutar:
`npm run qa:p2p && npm run qa:o2c && npm run qa:inventory && npm run qa:admin-finance && npm run qa:hr && npm run qa:crm-parties && npm run qa:pos && npm run qa:intelligence-ai && npm run qa:core-saas`

Después ejecutar `npm run build` y desplegar frontend.
