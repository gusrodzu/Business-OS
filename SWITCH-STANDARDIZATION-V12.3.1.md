# BuzzBee ERP v12.3.1 — Switch Standardization

Se estandariza el control visual de cambio de estado en todo el sistema.

- Tamaño único: 40 × 22 px.
- Indicador interno: 16 × 16 px.
- Recorrido: 18 px.
- Misma geometría en tablas, listas, formularios y modales.
- Se evita el efecto de desplazamiento vertical al hacer hover.
- Se conserva foco visible y semántica accesible `role="switch"` / `aria-checked`.
- No hay cambios de Prisma, API ni base de datos.
