# BuzzBee v17.5.2 — Unified Color System

Smart Import becomes the canonical visual color reference for the ERP.

## Canonical light palette
- Primary: `#2F6BFF`
- Primary hover: `#2459D6`
- Primary soft: `#EAF2FF`
- Primary border: `#C9DBFF`
- App background: `#F5F7FC`
- Surface: `#FFFFFF`
- Surface alt: `#F8FAFC`
- Border: `#D9E2F2`
- Divider: `#E7ECF5`
- Main text: `#0F172A`
- Secondary text: `#667085`
- Muted text: `#94A3B8`

Semantic colors are reserved for state only: success, warning, danger and info.
Historical purple/indigo decorative accents are mapped to the canonical BuzzBee blue.
